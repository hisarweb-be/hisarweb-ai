# Payment logos

Local copies of the brand marks used by `TrustBlock`
(`web/src/features/hw/components/trust-block.tsx`). No hotlinks, no redrawn
imitations. The trademarks stay with their owners; the files are shown only to
say which payment methods and security checks apply, as the brand guidelines
allow. Retrieved on 2026-10-24.

## Changes to the files

- The four Simple Icons files are the upstream SVGs with the brand colour set as
  `fill` (Simple Icons ships them without a colour). Shapes are unchanged.
- `troy.svg` is the unchanged official file.

## Not included

- 3-D Secure: Visa, Mastercard and others publish their own programme marks
  (Verified by Visa, Mastercard ID Check) and there is no freely usable official
  SVG of "3D Secure" itself. The page shows a plain text label instead of an
  imitation. Replace it when a licensed mark is obtained.

## Open points

- Troy: the guideline and media center do not state web shop usage terms in so
  many words. Ask Troy or the acquiring bank to confirm before launch.
- Mastercard: upgrade to the official two-colour artwork.

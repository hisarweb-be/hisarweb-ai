HISARWEB AI
HisarWeb AI:
ilk yanıtınıza 5 adım
Hesap açmaktan Claude Code'a kadar
Adım 1
Hesap açın
Kullanıcı adı seçin
Parola belirleyin (8-128 karakter)
Sözleşmeyi onaylayın, Hesap oluştur'a basın
Adım 2
250 TL startbonusunu alın
E-posta adresinizi ekleyin ve onaylayın
Telegram hesabınızı bağlayın
Telefon numaranızı HisarWeb botuyla paylaşın
Adım 3
API anahtarı oluşturun
API Anahtarları sayfasında oluşturun
Ad: claude-code
Grup: Ücretsiz deneme ya da Ücretli
Anahtarı kopyalayın
İsteğe bağlı
Bakiye yükleyin
Sayfa: /satin-al
%50 indirimilk alışveriş, 1000 TL'ye kadar
%15 indirimsonraki alışverişler
30 günteklifler geçerli
Adım 4
Playground'da deneyin
Soldan Playground'u açın
Modeli seçin
Mesajınızı yazın, Gönder'e basın
Adım 5
Claude Code'u bağlayın
Dosyayı açın: ~/.claude/settings.json
Adresin sonuna /v1 eklemeyin
BURAYA_ANAHTARINIZ yerine anahtarınızı yazın
Terminalde claude yazın
~/.claude/settings.json
{
"env": {
"ANTHROPIC_BASE_URL": "https://api.hisarweb.be",
"ANTHROPIC_AUTH_TOKEN": "BURAYA_ANAHTARINIZ"
}
}
$ claude
Hazırsınız
